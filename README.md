# AlphaLens

An LLM-powered equity research copilot. Ingests market data, news, and filings for a stock and produces a structured, evidence-backed research brief using a RAG + agent pipeline with a fine-tuned sentiment model.

Status: In development.

## Stack

Python, LLM APIs, RAG, ChromaDB, Llama/QLoRA, FastAPI

## Setup

Create a venv, activate it, then install from requirements.txt.
